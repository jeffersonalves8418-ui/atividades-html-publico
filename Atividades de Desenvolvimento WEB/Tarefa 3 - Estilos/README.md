# Tarefa 3 — Estilos

Abra `index.html` no navegador para ver o cartão de visita e o currículo estilizados.

- **Cartão de visita.** O bloco `<style>` define o fundo, a fonte e a cor do texto. O atributo `style` define o tamanho da imagem e a cor do cargo.
- **Currículo.** As folhas externas `estilos/estilo1.css` e `estilos/estilo2.css` definem dois visuais, com fontes, cores, margens, bordas da tabela e marcadores de lista diferentes.

Para comparar os estilos, altere no mesmo `index.html` o `href` do `<link rel="stylesheet">` de `estilos/estilo1.css` para `estilos/estilo2.css`. Salve e atualize o navegador.
